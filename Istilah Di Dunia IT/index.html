Kamus Coding dan Bahasa Pemrograman

Bingung dengan kata-kata seperti server, bug, atau database? Di sini semuanya dijelaskan dengan bahasa sehari-hari, lengkap dengan contoh yang mudah dibayangkan. Bahasa pemrograman seperti Python dan PHP juga ada, lengkap dengan contoh kodenya.

Mulai membaca

bug

/bʌɡ/   kata benda

Kesalahan pada program yang membuat hasilnya tidak sesuai harapan.

Contoh: tombol login tidak bisa diklik karena ada bug di kodenya.

ABCDEFGHIJKLMNOPQRSTUVWXYZ

A

Dasar

Algoritma

Urutan langkah yang jelas untuk menyelesaikan suatu masalah.

Seperti resep masakan: langkahnya berurutan dan hasilnya selalu sama.

B

Web

Backend

Bagian di balik layar yang mengolah data dan menjalankan logika aplikasi.

Seperti dapur restoran: pelanggan tidak melihatnya, tapi di sanalah makanan dibuat.

Jaringan

Bandwidth

Jumlah data yang bisa lewat melalui jaringan dalam waktu tertentu.

Seperti lebar jalan: makin lebar, makin banyak kendaraan yang bisa lewat sekaligus.

Web

Browser

Aplikasi yang dipakai untuk membuka dan menjelajahi situs web.

Contohnya Google Chrome, Mozilla Firefox, dan Microsoft Edge.

Dasar

Bug

Kesalahan pada program yang membuat hasilnya tidak sesuai harapan.

Tombol "Kirim" ditekan, tetapi tidak terjadi apa-apa.

C

Bahasa

C

Salah satu bahasa tertua yang masih dipakai. Cepat dan menjadi dasar banyak bahasa lain.

Dipakai untuk: sistem operasi, mikrokontroler, perangkat keras

printf("Halo, dunia!");
Bahasa

C#

Bahasa buatan Microsoft yang rapi dan kuat, populer di dunia pengembangan gim.

Dipakai untuk: gim dengan Unity, aplikasi desktop

Console.WriteLine("Halo, dunia!");
Bahasa

C++

Bahasa yang sangat cepat dan dekat dengan perangkat keras, tetapi lebih rumit dipelajari.

Dipakai untuk: gim besar, sistem, perangkat embedded

std::cout << "Halo, dunia!";
Web

Cache

Penyimpanan sementara agar halaman yang pernah dibuka bisa tampil lebih cepat.

Seperti menaruh buku yang sering dibaca di atas meja, bukan di rak jauh.

Web

CSS

Bahasa untuk mengatur tampilan halaman web, seperti warna, ukuran huruf, dan tata letak.

Kalau HTML adalah kerangka rumah, CSS adalah cat dan dekorasinya.

D

Data

Database

Tempat menyimpan data secara terorganisir agar mudah dicari dan dikelola.

Seperti lemari arsip sekolah yang menyimpan data seluruh siswa.

Dasar

Debugging

Proses mencari dan memperbaiki bug pada program.

Seperti mencari tahu kenapa lampu mati, lalu menggantinya dengan yang baru.

Jaringan

Domain

Nama alamat sebuah situs web yang mudah diingat manusia.

Contohnya google.com, sebagai pengganti deretan angka alamat server.

E

Jaringan

Enkripsi

Cara mengacak data supaya hanya bisa dibaca oleh orang yang punya kunci.

Seperti surat yang digembok: hanya penerima yang punya kuncinya.

Dasar

Error

Pesan yang muncul ketika program menemui masalah dan tidak bisa berjalan.

Tulisan “404 Not Found” berarti halaman yang dicari tidak ditemukan.

F

Dasar

Framework

Kerangka kerja berisi kode siap pakai agar pembuatan aplikasi lebih cepat.

Seperti rumah setengah jadi: fondasi dan dindingnya sudah ada, tinggal dilengkapi.

Web

Frontend

Bagian aplikasi atau web yang dilihat dan digunakan langsung oleh pengguna.

Seperti ruang makan restoran: tempat pelanggan duduk dan menikmati hidangan.

G

Dasar

Git

Alat untuk mencatat riwayat perubahan kode dan bekerja bersama dalam satu proyek.

Seperti riwayat versi di dokumen: kamu bisa kembali ke versi lama kapan saja.

Web

GitHub

Situs untuk menyimpan proyek Git di internet agar bisa dibagikan dan dikerjakan bersama.

Seperti Google Drive khusus untuk kode program.

H

Jaringan

Hosting

Layanan penyimpanan file website agar bisa diakses oleh siapa saja lewat internet.

Seperti menyewa lahan untuk mendirikan toko agar bisa dikunjungi orang.

Web

HTML

Bahasa untuk menyusun struktur halaman web, seperti judul, paragraf, gambar, dan tautan.

Seperti tulang pada tubuh: memberi bentuk dasar pada halaman.

I

Jaringan

IP Address

Deretan angka sebagai alamat unik setiap perangkat yang terhubung ke jaringan.

Seperti alamat rumah, supaya data tahu ke mana harus dikirim.

J

Bahasa

Java

Bahasa serbaguna yang kodenya bisa dijalankan di banyak jenis perangkat.

Dipakai untuk: aplikasi Android, sistem perusahaan

System.out.println("Halo, dunia!");
Bahasa

JavaScript

Bahasa yang membuat halaman web bisa bergerak dan berinteraksi dengan pengguna.

Dipakai untuk: website interaktif, aplikasi web

console.log("Halo, dunia!");

K

Dasar

Kode sumber

Tulisan perintah buatan programmer sebelum diubah menjadi aplikasi.

Seperti naskah film sebelum filmnya dibuat.

Dasar

Kompiler

Program yang menerjemahkan kode buatan manusia menjadi bahasa yang dimengerti komputer.

Seperti penerjemah yang mengubah bahasa Indonesia menjadi bahasa Inggris.

L

Dasar

Library

Kumpulan kode siap pakai yang bisa dipanggil agar tidak perlu menulis dari nol.

Seperti meminjam buku di perpustakaan: tinggal pakai.

Dasar

Loop

Perulangan: perintah yang dijalankan berkali-kali sampai syaratnya terpenuhi.

Seperti menyuruh komputer menulis namamu 100 kali.

M

Data

MySQL

Sistem database populer yang menyimpan data dalam bentuk tabel.

Seperti buku besar berisi banyak tabel, dan tiap tabel berisi baris-baris data.

N

Web

Node.js

Teknologi yang membuat JavaScript bisa dijalankan di server, bukan hanya di browser.

JavaScript yang tadinya hanya mengurus tampilan kini bisa mengurus backend juga.

O

Dasar

Open source

Perangkat lunak yang kodenya terbuka, boleh dilihat, dipelajari, dan dikembangkan siapa saja.

Seperti resep yang dibagikan gratis: siapa pun boleh mencoba dan memperbaikinya.

P

Bahasa

PHP

Bahasa yang berjalan di server untuk membuat website dinamis yang terhubung ke database.

Dipakai untuk: website, toko online, sistem informasi

echo "Halo, dunia!";
Bahasa

Python

Sintaksnya sederhana dan mirip bahasa Inggris, sehingga cocok untuk pemula.

Dipakai untuk: kecerdasan buatan, analisis data, otomatisasi

print("Halo, dunia!")

Q

Data

Query

Perintah untuk meminta atau mengubah data di dalam database.

Seperti bertanya ke petugas arsip: “siapa saja siswa kelas 10?”

R

Web

Responsif

Tampilan web yang otomatis menyesuaikan ukuran layar, baik di HP, tablet, maupun laptop.

Seperti air yang menyesuaikan bentuk gelas tempat ia dituang.

S

Jaringan

Server

Komputer yang selalu menyala untuk melayani permintaan dari perangkat lain.

Seperti pelayan restoran yang mengantarkan pesanan sesuai permintaan pelanggan.

Data

SQL

Bahasa khusus untuk mengambil, menambah, dan mengubah data di dalam database.

Seperti kalimat perintah untuk petugas arsip: "carikan data siswa kelas 10".

T

Bahasa

TypeScript

JavaScript yang ditambah aturan tipe data, sehingga kesalahan mudah ketahuan sebelum program dijalankan.

Dipakai untuk: aplikasi web berukuran besar

console.log("Halo, dunia!");

U

Web

UI/UX

UI adalah tampilan antarmuka, sedangkan UX adalah kenyamanan saat menggunakannya.

UI seperti desain toko, UX seperti mudah atau tidaknya menemukan barang.

Jaringan

URL

Alamat lengkap sebuah halaman atau file di internet.

Seperti alamat rumah lengkap dengan nomor rumah dan nama gang.

V

Dasar

Variabel

Wadah bernama untuk menyimpan nilai di dalam program.

Seperti kotak berlabel "nama" yang isinya bisa diganti kapan saja.

W

Web

Website

Kumpulan halaman web yang saling terhubung dan dibuka lewat browser.

Seperti buku: setiap halaman web adalah satu lembarnya.

Web

Wireframe

Sketsa kasar tata letak halaman sebelum dibuat sungguhan.

Seperti denah rumah sebelum rumahnya dibangun.

X

Web

XAMPP

Paket aplikasi gratis untuk menjalankan server di komputer sendiri, berisi Apache, MySQL, dan PHP.

Berguna untuk mencoba website PHP tanpa perlu hosting.

Data

XML

Format penulisan data memakai tag, mirip HTML, agar mudah dibaca mesin.

Seperti formulir dengan kolom berlabel jelas untuk setiap isian.

Y

Data

YAML

Format penulisan pengaturan atau data yang ringkas dan mudah dibaca manusia.

Seperti catatan bertingkat yang disusun dengan menjorok ke dalam.

Z

Dasar

ZIP

Format file yang memampatkan satu atau banyak file menjadi satu file berukuran lebih kecil.

Seperti memasukkan baju ke tas vakum agar muat lebih banyak.
